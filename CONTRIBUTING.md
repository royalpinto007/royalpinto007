# Contributing

This is my personal site, so content changes are mine to make, but fixes are welcome.

Good pull requests:

- bug fixes (layout, mobile, accessibility, performance)
- broken links or typos
- improvements that also help people using this repo as a template

Before opening one:

1. Open an issue first for anything bigger than a small fix.
2. Run `npm run lint` and `npm run build`.
3. Keep the pull request focused on one change.

Please do not change the written copy, projects or personal images; those stay as they are.
