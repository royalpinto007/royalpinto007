# Home scene art

## Distinct chapter artwork

The studio is reserved for Home's selected work. Projects has an original arcade cabinet; Contact has an original glass telephone. The reel uses procedural celluloid/aperture graphics shared only between its static and playing states. The footer is an open coastal horizon and original illustrated sailboat, with independent wave/reflection and boat movement. These have distinct silhouettes and motion, within the same light blue/rose/peach identity. No scene defaults to studio: callers explicitly select a kind.

The built-in image-generation tool created the arcade, telephone and sailboat. Original PNGs remain outside the repository. Production assets are `public/scene/arcade.webp`, `arcade-mobile.webp`, `telephone.webp`, `telephone-mobile.webp`, `sailboat.webp` and `sailboat-mobile.webp`. Responsive renditions preserve transparency, use native lazy loading, and do not add requests to the Home hero. The final prompts are below.

## Original hero environment

The built-in image-generation tool created the sunset environment. Royal's original illustrated portrait served only as the style and palette reference; the portrait itself remains unchanged. The environment is rendered separately from the original portrait, whose silhouette is clipped in CSS.

Production assets:

- `public/scene/sunset-coast.webp`
- `public/scene/sunset-coast-mobile.webp`

Final generation prompt:

> Use case: stylized-concept. Asset type: panoramic background environment for a personal software engineer portfolio hero, 16:9 landscape, no UI, no lettering. Use the attached portrait ONLY as an illustration style and color reference; do not reproduce or include the man. Create a cinematic coastal sunset world with luminous sky blue, muted violet, dusty pink clouds, warm peach sunlight and sparkling reflections. Composition: an open, spacious pale sky occupies the upper two thirds, with especially calm light-blue and peach negative space across the LEFT half for dark navy website typography. A glowing low sun on the RIGHT, a reflective ocean and a distant coastal skyline along the lower quarter; a few elegant palm silhouettes only at the far right edge. Painterly illustration with sophisticated natural atmospheric depth, premium cinematic game key-art lighting inspired by a sunlit Miami coast. Strong focal lighting and beautiful reflected glints, balanced color, no full-canvas neon saturation. Foreground should remain clear so a separate interactive portrait can float on the right. Not a photograph, not a website mockup. No people, cars, logos, typography, borders, or watermarks. The original portrait file will remain unchanged and be layered separately in code.

The original generated PNG stays outside the repository. The production WebP copies are approximately 141 KB and 48 KB. CSS supplies small water glints, lighting and slow camera drift; the generated raster is a still environment. A shared pause control and visibility/reduced-motion handling govern those effects. Pointer parallax moves the unchanged portrait as one layer; a lighting selector changes the environment treatment.

The original 460px portrait is still byte-identical. `public/scene/portrait-silhouette.svg` is a vector contour mask used in CSS to exclude the original sky. The refined contour follows the hair, cheek and neck, rounds small steps with quadratic curves, and applies a 0.65-source-pixel morphological inset to exclude edge antialiasing. The mask is checked at three times source size on ivory and vivid pink backgrounds. It contains no generated foreground pixels. An experimental generated cutout was rejected because it redrew facial details and is not shipped. The existing coast remains the hero environment. The daylight scenes below extend the art direction through supporting sections.

## Loading behaviour

Scene images are responsive, lazy, low-priority and dimensioned. The mobile hero loads the small coast and portrait renditions. Supporting sections no longer trigger an extra desktop coast download on mobile. Shared navigation avoids eager route prefetching. On coarse-pointer/mobile screens, the optional GSAP bundle starts after the first scene has painted and the browser is idle, or on the first scroll/touch. A compositor CSS headline entrance runs independently. The deferred bundle does not re-hide content already on screen; route and media changes cancel pending work. CSS uses ordinary cached stylesheet delivery instead of serializing every stylesheet into each HTML document. The unchanged green contribution SVG loads near its viewport, with a visible error/retry and direct-link fallback, plus a native image/link without JavaScript. Its original dates, counts and colors are preserved. `scripts/check-home-loading.py` checks these boundaries and error recovery in the browser.
