# Home environments

Seven original generated environments carry scenery across the Home sections. These decorative backgrounds do not depict real project interfaces. The product diagrams, links and architecture controls remain HTML.

Assets: `public/scene/environments/{name}.webp` and `{name}-mobile.webp`. Mobile files use separately recomposed portrait artwork, not enlarged landscape crops. Original generated PNG files are retained in the local image-generation archive. No external artwork or supplied video footage is embedded.

Images are requested when a chapter enters the viewport, below the initial hero. Fine pointers get bounded scroll-linked camera/light movement. Reduced motion, pause, no JavaScript and image-failure alternatives remain available.
